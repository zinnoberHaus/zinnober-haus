---
name: release-readiness
description: Audit an actual product release against installability, enterprise operations and open-source obligations.
---

Read product acceptance criteria and release scope. Verify clean installation, supported versions, migration/rollback, backup and restore, access controls, secret handling, audit records, dependency licenses, tests and release artifacts. For Zettel test work/document/table permissions and automation boundaries. For Carthouse test retry/idempotency, lineage, credentials, query limits and approval boundaries for generated DAGs. Record each requirement with direct evidence or a blocker. A green scaffold check is not release evidence. Publish only with authorization and never call an incomplete audit passed.
