# Initial license decision

Adopt Apache-2.0 for original work in the orchestration repository, Zettel and Carthouse. This follows the enterprise adoption and permissive integration recommendation in the research. Keep core features, identity controls and self-hosting tooling open; optional hosting and support can fund maintenance.

Preserve third-party notices and inspect licenses at pinned versions. Do not copy AGPL implementation into these repositories without a deliberate compatibility decision. Project names are provisional pending name/trademark review. License choice does not establish trademark clearance.
