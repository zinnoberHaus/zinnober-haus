# Agent operating context

Read README.md, registry/repos.json, the relevant research brief and docs/operations/workflow.md before work.

## Scope

This repository owns shared policy, skills, roles, repository registry and portfolio decisions. Zettel and Carthouse own their implementation and product-specific decisions.

Never modify microyee-ai, mircoyee-ai, or repositories belonging to another owner. Repository cleanup is a one-time operation with an explicit inventory, backups and a recorded outcome; it is not recurring automation.

## Collaboration

The coordinating agent may delegate independent research, implementation and verification to bounded agents. Assign file ownership, inspect their evidence, and reconcile conflicts before integrating. Do not expose secrets or private backup contents in public repositories.

## Definition of done

Meet acceptance criteria, run relevant checks, document deployment and recovery effects, update status honestly, and record unresolved risks. Never equate a scaffold or successful CI with a completed product. Do not invent source citations, benchmark results, security assurances or feature parity.
